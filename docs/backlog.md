## Pinterest-inspired ideas board (proposed 3 Oct 2026)

The founder said the ideas tab "almost reminds me of like a pinterest but for like travel".
Proposed ways to lean into that. Recommended first: 1, 3, 4 (most Pinterest feel for the least
work), then 5 (cheap).

| # | Idea | Notes |
|---|---|---|
| P1 | **Masonry photo grid**: Pinterest-style tall photo cards, title over the image, vote chips below. Default on desktop; Board and List one tap away | Uses the Google place photos we already fetch (D73) |
| P2 | **"More like this"**: on an open idea, related places nearby or in the same category, one tap to save | Suggestions come only from places data; never paid placement (§11 trust rules) |
| P3 | **Sections inside a city**: e.g. "Food · Day trips · Nightlife", auto-built from categories, renamable | Like Pinterest board sections |
| P4 | **Quick save from anywhere**: hover (desktop) or long-press (phone) a card for "Save to…" a trip, city or library board | Like Pinterest's one-tap Save |
| P5 | **Group activity on the card**: face stack of who added and commented, plus "3 Must-do" | Pass votes and non-voters still never shown (FR-42); hidden for surprise items (FR-91) |
| P6 | **Board covers**: each city, trip or library board gets a collage cover from its top ideas | Makes the trip list and library more visual |
| P7 | **Visual search in screenshots**: tap a spot in a screenshot to find the place (Pinterest Lens-style) | Bigger lift; later |
